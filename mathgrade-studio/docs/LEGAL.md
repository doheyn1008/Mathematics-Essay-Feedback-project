# Q.E.D. 약관·개인정보 문서 관리

현재 문서는 **검토안**이다. 시행일이 정해진 정식 약관이나 개인정보 처리방침으로 표시하지 않는다. 회원가입에서 검토안 동의를 받거나 이를 근거로 결제·환불 제한을 적용하지 않는다.

## 파일과 웹 페이지

- 단일 원문: `lib/legal-content.json`
- 웹 페이지: `/terms`, `/privacy`
- 다운로드: `public/legal/qed-terms-draft.pdf`, `public/legal/qed-privacy-draft.pdf`
- 개발·운영자와 이메일: `lib/site-info.ts` 및 법률 문서 원문의 연락처

PDF는 `scripts/build-legal-pdfs.py`가 같은 JSON 원문에서 생성한다. ReportLab이 설치된 Python으로 앱 폴더에서 `python scripts/build-legal-pdfs.py`를 실행한다. 생성된 두 PDF를 커밋하므로 앱 빌드·배포에 Python은 필요 없다. 원문을 바꾸면 PDF도 재생성하고 페이지를 이미지로 렌더링해 한글 글꼴·잘림·페이지 구분을 확인한다. `public/fonts/MathgradeKorean-Regular.ttf`와 해당 폰트 라이선스를 유지한다.

## 정식 시행 전에 확정할 사항

1. 현재 운영자는 사업자 등록 전이다. 유료 판매 전에 실제 사업 개시 시점에 따른 사업자 등록, 통신판매업 신고 적용 여부와 판매자 정보 표시 의무를 확인한다. 사업자 등록 기한과 판매 전 표시·신고 의무를 같은 것으로 취급하지 않는다. 등록하지 않은 상호·번호·주소·전화번호를 만들지 않는다.
2. 수집 목적별 적법한 처리 근거와 필수·선택 항목, 가입 대상 연령, 만 14세 미만 법정대리인 확인 방식을 확정한다. 실제 절차 없이 보호자 동의를 받는다고 쓰지 않는다.
3. Cloudflare 계정·계약과 D1/R2의 실제 데이터 위치를 확인해 이전 국가, 수령자 연락처, 항목·시점·방법·목적·기간·근거와 거부 방법을 채운다. 미국 회사라는 이유만으로 모든 데이터의 저장 국가를 미국으로 쓰지 않는다.
4. 세션·접속/보안 로그·백업·원본 파일·학습 기록·전화 인증 중복 방지값의 보관 근거와 기한, 실제 삭제 작업을 구현·검증한다. 현재 탈퇴는 인증 수단 제거와 일부 표시 이름 변경을 포함하며 모든 원본 파일의 물리적 삭제가 아니다.
5. 학생 자료의 선생님 업로드와 담당자 열람, 문제 기여·프리미엄 제공의 법적 관계와 동의 범위를 확인한다.
6. AI·문자·소셜 로그인·알림·광고·결제 서비스를 연결하기 전에 실제 제공자, 위탁·제3자 제공·국외 처리 여부 및 필요한 안내·동의를 반영한다.
7. 실제 상품의 가격, 제공 횟수·기간·자동 갱신 여부와 해지·환불 정책, 포인트 조건을 확정한다. 관리자의 무상 운영 권한을 결제 내역으로 만들지 않는다.
8. 개인정보 보호책임자와 요청 처리 절차를 확정하고 원문·웹·PDF에 같은 버전과 시행일을 반영한다. 검토안 표시를 제거하는 것은 위 사항과 실제 운영을 확인한 다음 진행한다.

## 작성 근거

현재 소스의 로그인·계정/반/학습 기록·탈퇴 처리와 아래 공식 자료를 대조해 작성했다. 저장 위치·보관 기간 등 확인되지 않은 운영 사실은 명시적으로 남겨 두었다.

- [개인정보보호위원회 2026 개인정보 처리방침 작성지침](https://www.privacy.go.kr/front/bbs/bbsView.do?bbsNo=BBSMSTR_000000000049&bbscttNo=20885)
- [개인정보 보호법](https://www.law.go.kr/법령/개인정보보호법): 제22조의2, 제28조의8, 제30조 및 정보주체 권리 관련 조항
- [전자상거래 등에서의 소비자보호에 관한 법률](https://www.law.go.kr/법령/전자상거래법): 판매자 정보·거래 조건과 청약철회 관련 조항
