# 수식채점실 관리자

`/admin`은 수식채점실의 회원 목록과 상세 화면을 제공한다. 이름과 서비스 아이디로 검색하고 계정 유형으로 목록을 좁힐 수 있다. 전체 가입 인원과 학원용 선생님·학원 학생·개인 학습자·유형 미등록 인원은 현재 계정 유형을 기준으로 집계한다. 검색 결과 수는 별도로 표시한다.

사이트 소유자는 수식채점실 상단의 **관리자 센터** 버튼으로 이동할 수 있다. 관리자 센터 상단의 **수식채점실로 이동** 버튼으로 서비스 화면에 돌아온다. 관리자 센터 버튼은 서버가 소유자 권한을 확인한 뒤 표시된다.

## 회원 유형 변경

회원 관리에서 회원을 연 뒤 **서비스 계정 유형**을 선생님, 학원 학생, 개인 학습자 중 하나로 지정하고 저장한다. 저장된 유형은 수식채점실의 메뉴와 서버 권한 검사에 반영된다. 유형을 변경하면 이전·이후 유형, 변경한 관리자와 시각을 서버 감사 기록에 저장한다. 유형 지정과 유료 이용권 발급은 별도 기능이다.

현재 반에 소속되어 있거나 반의 이용권 부담자로 지정된 회원은 담당 관계를 먼저 정리해야 유형을 바꿀 수 있다. 변경할 유형과 맞지 않는 활성 이용권도 먼저 정리해야 한다. 안내 메시지에 해당 사유가 표시된다. 회원의 로그인 ID, 제출 기록 및 이용권 내역은 보존된다.

배포에서 서버 환경 변수 `ADMIN_SITE_ORIGIN`에는 수식채점실 주소의 원점(예: `https://your-site.chatgpt.site`)을, `ADMIN_OWNER_EMAIL`에는 확인된 Sites 소유자 계정 이메일을 설정한다. 둘 중 하나라도 없거나 요청 원점이 일치하지 않으면 관리자 API를 사용할 수 없다. Sites가 인증한 방문자 헤더만 사용하며, 서비스 자체 로그인과 선생님 역할은 관리자 인증에 영향을 주지 않는다. 인증 헤더를 검증하는 Sites 앞단 없이 Worker를 직접 공개하는 환경에서는 관리자 인증을 활성화하지 않는다. 기존 소유자 전용 사이트의 접근 정책과 별개로 관리자 API에서 요청마다 검사한다.

목록에는 이름, 서비스 아이디, 유형, 가입 시각을 표시한다. 상세에서는 전화번호 인증 여부와 이용권을 함께 확인할 수 있다.
