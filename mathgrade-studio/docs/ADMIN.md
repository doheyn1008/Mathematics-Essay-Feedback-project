# 수식채점실 관리자

`/admin`은 수식채점실의 회원 목록과 상세 화면을 제공한다. 이름과 서비스 아이디로 검색하고 계정 유형으로 목록을 좁힐 수 있다. 전체 가입 인원과 학원용 선생님·학원 학생·개인 학습자·유형 미등록 인원은 현재 계정 유형을 기준으로 집계한다. 검색 결과 수는 별도로 표시한다.

사이트 소유자는 수식채점실 상단의 **관리자 센터** 버튼으로 이동할 수 있다. 관리자 센터 상단의 **수식채점실로 이동** 버튼으로 서비스 화면에 돌아온다. 관리자 센터 버튼은 서버가 소유자 권한을 확인한 뒤 표시된다.

## 회원 유형 변경

회원 관리에서 회원을 연 뒤 **서비스 계정 유형**을 선생님, 학원 학생, 개인 학습자 중 하나로 지정하고 저장한다. 저장된 유형은 수식채점실의 메뉴와 서버 권한 검사에 반영된다. 유형을 변경하면 이전·이후 유형, 변경한 관리자와 시각을 서버 감사 기록에 저장한다. 유형 지정과 유료 이용권 발급은 별도 기능이다.

현재 반에 소속되어 있거나 반의 이용권 부담자로 지정된 회원은 담당 관계를 먼저 정리해야 유형을 바꿀 수 있다. 변경할 유형과 맞지 않는 활성 이용권도 먼저 정리해야 한다. 안내 메시지에 해당 사유가 표시된다. 회원의 로그인 ID, 제출 기록 및 이용권 내역은 보존된다.

## Cloudflare Workers 관리자 지정

1. 먼저 실제 배포 사이트에서 자신의 수식채점실 계정을 가입한다. 계정 유형은 관리자 권한과 별개이므로 필요한 유형을 선택한다.
2. 운영 D1의 `product_credentials`에서 자신의 서비스 아이디에 해당하는 `user_id`를 확인한다. GitHub 아이디·이메일·표시 이름과는 다른 고유 식별자다.
3. 서버 secret `ADMIN_OWNER_USER_ID`에 그 ID를 지정한다.
4. `wrangler.json`의 `vars.ADMIN_SITE_ORIGIN`에 실제 사이트의 HTTPS 원점(예: `https://qed.it.kr`)을 지정하고 다시 배포한다. 경로와 마지막 `/`를 붙이지 않는다.
5. 같은 계정으로 로그인한 뒤 메인의 **관리자 센터** 버튼 또는 `/admin`으로 이동한다.

명령 예시와 전체 배포 순서는 [운영 가이드](../../docs/OPERATIONS.md)에 있다. `DEPLOYMENT_TARGET=cloudflare`에서만 이 방식을 사용한다. 설정한 회원 ID와 유효한 세션이 모두 일치해야 하며 로그아웃·만료·탈퇴 시 관리자 접근도 사라진다. 이메일이 같거나 선생님 유형을 선택했다는 이유로 관리자 권한을 부여하지 않는다. 설정한 HTTPS 원점에서 시작한 변경 요청만 허용한다. 소유자를 바꾸려면 새 계정의 ID로 서버 설정을 교체한다. 고객 유형 변경 화면으로 관리자를 추가할 수 없다.

## 기존 ChatGPT Sites 관리자

Sites 배포에서는 `ADMIN_SITE_ORIGIN`에 Sites 주소의 원점을, `ADMIN_OWNER_EMAIL`에 확인된 Sites 소유자 이메일을 설정한다. 신뢰된 Sites ingress의 인증 헤더를 확인하며 일반 회원 세션이나 선생님 유형은 관리자 권한을 부여하지 않는다. 이 이메일 방식은 공개 Workers 배포용이 아니다.

목록에는 이름, 서비스 아이디, 유형, 가입 시각을 표시한다. 상세에서는 전화번호 인증 여부와 이용권을 함께 확인할 수 있다.
