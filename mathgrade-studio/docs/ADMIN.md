# 수식채점실 관리자

`/admin`에서 수식채점실과 같은 데이터베이스의 고객, 반, 시험 제출 현황을 확인한다. 고객 검색과 고객 상세의 응대 상태·내부 메모를 제공한다. 메모는 관리자에게만 표시하며 변경 주체와 시각, 버전을 감사 기록에 남긴다. 응대 상태는 업무 분류 값이며 회원 자격과 이용권을 바꾸지 않는다.

배포에서 서버 환경 변수 `ADMIN_SITE_ORIGIN`에는 수식채점실 주소의 원점(예: `https://your-site.chatgpt.site`)을, `ADMIN_OWNER_EMAIL`에는 확인된 Sites 소유자 계정 이메일을 설정한다. 둘 중 하나라도 없거나 요청 원점이 일치하지 않으면 관리자 API를 사용할 수 없다. Sites가 인증한 방문자 헤더만 사용하며, 서비스 자체 로그인과 선생님 역할은 관리자 인증에 영향을 주지 않는다. 인증 헤더를 검증하는 Sites 앞단 없이 Worker를 직접 공개하는 환경에서는 관리자 인증을 활성화하지 않는다. 기존 소유자 전용 사이트의 접근 정책과 별개로 관리자 API에서 요청마다 검사한다.

목록에는 이름, 서비스 아이디, 유형, 가입 시각, 응대 상태를 표시한다. 상세에는 전화번호 인증 여부, 이용권 및 표시 가능한 포인트 잔액, 반 소속과 최근 제출 요약이 포함된다. 비밀번호, 인증번호, 전화번호, 학생 원본 답안, 첨삭 본문 및 대화는 관리자 조회 응답에 포함되지 않는다. 결제·포인트 조정과 외부 메시지 발송은 연결 범위에 포함되지 않는다.
