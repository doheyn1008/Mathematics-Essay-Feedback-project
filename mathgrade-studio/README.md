# 수식채점실

수학 강사용 논술·서술형 첨삭 작업대입니다.

## 실행

이 폴더에서 `python3 -m http.server 8000`을 실행하고 브라우저에서 `http://localhost:8000`을 엽니다. 외부 패키지와 API 키 없이 실행할 수 있습니다.

예시 답안 A-001에서 채점 근거를 확인한 뒤 부분점수와 피드백을 수정하고 확정할 수 있습니다. 새 답안은 수동으로 채점하며, 채점 확정 결과를 CSV로 받을 수 있습니다. 사진과 PDF 원본은 첨부한 탭이 열려 있는 동안 미리 볼 수 있습니다. 답안 텍스트와 채점 결과는 해당 브라우저에 저장됩니다.

실제 AI 판독 및 자동 채점에는 서버와 API 연결이 필요합니다. 함께 제공된 도입 검토 PDF에 연결 방식, 비용 가정과 파일럿 검증 항목을 정리했습니다.
