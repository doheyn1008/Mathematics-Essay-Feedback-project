# 수식채점실

사용자가 가져온 수학 시험과 손글씨 답안을 한 건으로 제출하고, 선생님이 문항별 첨삭·총평을 검토하는 시험 작업공간입니다. PR #1 작성자의 계정·반·시험 요구사항을 반영한 개발 버전입니다.

## 실행과 확인

Node.js 22.13 이상을 사용합니다.

```sh
npm ci
npm test
npx tsc --noEmit
npm run build
npm run dev
```

로컬 D1에는 `drizzle/`의 모든 SQL 마이그레이션을 파일명 순서대로 적용합니다. 기존 테이블은 보존됩니다. Sites에서는 패키지의 SQL 마이그레이션이 적용됩니다. 로컬과 배포 데이터베이스는 별개입니다.

일반 Cloudflare Workers가 기본 실행·빌드 대상입니다. 로컬 DB 준비는 `npm run db:migrate:local`을 사용합니다. [Workers 배포 안내](docs/CLOUDFLARE_DEPLOYMENT.md)에 D1·R2 설정과 배포 절차를 정리했습니다. 기존 Sites 빌드는 `npm run build:sites`, Sites 모의 인증 개발은 `npm run dev:sites`로 명시적으로 선택합니다.

## 사용 흐름

`/login`에서 아이디와 비밀번호로 가입·로그인한다. 로그인 후 메인에서 작업공간을 연다. 기존 ChatGPT 계정에 수식채점실 기록이 있으면 로그인 화면에서 **기존 ChatGPT 계정으로 계속**을 선택해 기존 계정과 기록을 이어서 사용할 수 있다. Sites 방문 권한과 수식채점실 회원 인증은 별도다.


메인 소개 → 자체 아이디·비밀번호 가입/로그인 → 이름과 인사가 있는 메인 → 시작하기 → 작업공간으로 이동합니다. Google·카카오 로그인과 기존 계정 연결은 OAuth 설정이 있을 때 활성화됩니다. 선생님은 여러 반의 시험·과제·학생을 관리하고 학생을 선택해 대리 제출할 수 있습니다. 학원 학생은 반 참여 후 배정 시험에 답안 사진/PDF와 질문만 제출합니다. 개인은 자신의 문제와 손글씨 풀이를 함께 제출합니다.

선생님은 반 → 시험 → 학생 → 첨삭 상세 순서로 이동합니다. 학생과 개인은 본인 시험 기록만 확인합니다. 상세를 열어 문항별 점수·총평·질문 답변과 변경 이력·비공개 대화를 확인합니다. 선생님 검토 후 공개와 AI 결과 즉시 공개는 별도 설정이며, 공개 상태와 검토 완료 여부를 구분합니다. 최신 허용 결과를 웹과 A4 PDF로 확인합니다.

일반 시험 등록에는 출처나 제공 동의가 필요하지 않습니다. 등록 하단의 기여 체크박스를 선택하면 출처·권한·유료 프리미엄 제공 동의 입력이 나타납니다. 별도 문제 기여 화면도 사용할 수 있습니다. 유료 개인 프리미엄 제공 동의가 있는 문제만 제공하며, 프리미엄 목록·파일·가져오기에 서버 이용권 검사를 적용합니다. 일반 학생 제출은 자동 공유하지 않습니다.

모든 계정은 계정 설정에서 전화번호 인증 후 무료 첨삭 1회를 받을 수 있습니다. 계정·번호당 최초 한 번이며, 이용권이나 반 없이 직접 가져온 문제와 답안으로 체험합니다. AI 첨삭 성공 시에만 차감합니다. 문자 인증은 운영 연결 정보가 없으면 준비 중으로 표시합니다.

## 관리자

소유자 전용 `/admin`에서 수식채점실 회원을 검색하고 상세 정보를 확인하거나 계정 유형을 변경합니다. 설정은 [관리자 안내](docs/ADMIN.md)를 참고하세요.

이 관리자 인증은 기존 Sites 전용입니다. 일반 Workers에서는 ChatGPT 인증 헤더를 제거하므로 관리자 기능은 비활성화됩니다. Workers용 관리자 권한 이전은 별도 구현 대상입니다.

## 현재 동작 범위

자체 회원가입·로그인·로그아웃, 고정 계정 유형, 세션 인증과 알림 동의 저장은 동작합니다. Google·카카오 OAuth는 운영 키와 등록한 콜백 주소가 필요합니다. 알림 발송·실제 AI 제공자·결제는 **미연결**입니다. API 요청 묶음·결과 검증·공개 분기·버전/사용량 기록 구조는 구현되어 있지만 실제 모델 채점은 실행되지 않습니다. 미연결 요청으로 횟수를 차감하지 않습니다. 가격·횟수·포인트 지급 정책은 아직 정하지 않았습니다.

실제 유료 계정 권한은 서버 이용권이 있어야 활성화됩니다. 결제 버튼이나 역할 버튼으로 권한을 발급하지 않습니다. `?demo=1`에서는 합성 시험을 이용해 역할별 화면과 제출·검토·대화를 체험할 수 있습니다. 체험 기록은 실제 계정 데이터가 아닙니다.

Sites 배포는 기존 소유자 전용 범위를 유지합니다. 일반 Workers는 Sites 방문 권한을 사용하지 않으므로 비공개 테스트에는 별도 접근 제한을 설정해야 합니다.

자세한 모델·권한·연결 전 기능·미정 정책·기존 기록 이행은 [제품 구현 문서](docs/PRODUCT_IMPLEMENTATION.md)를 확인하세요.

## 구성

- `lib/product-types.ts` — 계정·반·시험·첨삭 버전·대화 계약
- `lib/server/product-*.ts`, `api-router.ts` — 인증·이용권·반별 권한·시험 API·기여/프리미엄
- `components/product-*.tsx` — 메인과 계정별 작업공간
- `lib/product-pdf.ts`, `lib/pdf-page.ts` — 시험 PDF와 원본 페이지 변환
- `db/`, `drizzle/` — 기존 자료를 보존하는 추가 마이그레이션
- `tests/` — 서버 권한·파일·이력·포인트·PDF·스크립트 회귀 검사

이전 브라우저 저장형 화면은 `/legacy/index.html`에서 기록 열람·CSV 내보내기가 가능합니다. 기존 서버 기록은 새 작업공간에서 한 문항 시험으로 읽기 전용 표시됩니다. 키와 학생 답안은 소스 저장소에 포함하지 않습니다.

추가 로그인·알림·포인트 설정과 운영 전 남은 연결은 [계정 및 사용 정책](docs/ACCOUNTS_AND_ACTIVITY.md)을 참고하세요.

계정 찾기·비밀번호 변경/재설정·탈퇴, 반/시험/과제 관리, 자료 버전과 대화 자동 갱신은 [후속 관리 구현](docs/FOLLOW_UP_MANAGEMENT.md)을 참고하세요. `0009_account_and_record_management.sql`이 추가되었습니다.
