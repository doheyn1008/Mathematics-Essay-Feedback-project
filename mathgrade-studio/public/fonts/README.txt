PDF font assets

MathgradeKorean-Regular.ttf is a modified subset and TrueType conversion of
Noto Sans CJK KR Regular, distributed under the SIL Open Font License 1.1.
Original source: https://github.com/notofonts/noto-cjk
Copyright and license: OFL-Noto.txt

The subset includes modern Hangul, Hangul Jamo, Latin, Greek, common punctuation,
mathematical symbols, and fullwidth forms. Cubic outlines were converted to
quadratic TrueType outlines using fontTools with one font-unit tolerance. The
font was renamed Mathgrade Korean to distinguish this modified distribution.

STIXGeneral.ttf supplies additional mathematical glyphs. Original source:
https://github.com/stipub/stixfonts
Copyright and license: LICENSE-STIX.txt

The prepared Korean subset is embedded intact; STIX is subset for each report.
Characters unavailable
in either font are printed using their Unicode code point and noted in the PDF.
