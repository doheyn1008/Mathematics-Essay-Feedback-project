채점 처리 흐름

  1. 이름과 학번을 가린 이미지 또는 PDF를 받습니다.
  2. 수식을 인식하고, 불명확한 줄을 강사에게 표시합니다.
  3. 채점기준별 제안점수, 답안 근거, 감점 사유를 생성합니다.
  4. 서버가 배점 범위와 합계를 검사하고 강사가 확정합니다.

연결 선택지

  • OpenAI Responses API로 사진·PDF 판독과 채점 초안을 한 번에 요청합니다.
  • 수식 인식이 부족하면 별도 OCR과 채점 모델을 조합합니다.
  • 도형, 대안 풀이, 판독 불가 답안은 강사 검토로 보냅니다.

비용과 품질 검증

답안당 입력·출력 토큰, 재시도 횟수, 강사 수정 시간과 점수 차이를 함께 기록합니다. 단건 처리부터 검증하고, 학급 단위 첨삭은 작업 대기열로 확장합니다.

현재 버전

예시 답안에는 작성된 채점 초안이 있습니다. 새 답안은 직접 채점하며 이미지·PDF는 브라우저에서 원문을 미리 볼 수 있습니다. 첨부 파일은 현재 탭에서만 유지됩니다.
